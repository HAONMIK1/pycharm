# 📍 이미지 기반 실내 위치 인식 네비게이션

사진 한 장으로 지도 위 현재 위치를 찾고, 목적지까지의 거리와 방향을 계산하는 컴퓨터 비전 프로젝트입니다.

---

## 어떤 프로젝트인가요?

GPS가 동작하지 않는 실내 환경에서, **지금 찍은 사진**과 **기준 지도 이미지**를 비교해 현재 위치를 파악합니다.

위치를 파악한 뒤 지도에서 목적지를 클릭하면, 목적지까지의 **거리(m)** 와 **회전해야 할 각도** 를 실시간으로 계산해 화면에 표시합니다.

```
현재 위치 사진 촬영
       ↓
SIFT 알고리즘으로 기준 지도와 매칭
       ↓
지도 위 현재 위치 자동 표시 (빨간 점)
       ↓
지도에서 목적지 클릭
       ↓
거리(m) + 회전 각도 실시간 계산 및 표시
       ↓
목적지 방향 안내 영상 재생
```

---

## 동작 원리

### SIFT (Scale-Invariant Feature Transform)
크기나 각도가 달라도 이미지의 고유한 특징점을 검출하는 알고리즘입니다.
현재 위치에서 찍은 사진과 기준 지도 이미지의 특징점을 비교해, 지도 위 어느 좌표에 해당하는지 계산합니다.

### 위치 계산 과정
1. 기준 지도(`map.jpg`)와 입력 사진에서 특징점 검출
2. BFMatcher로 두 이미지의 특징점 매칭 (상위 30개 선택)
3. RANSAC 기반 Homography 행렬 계산
4. 원근 변환으로 입력 사진의 지도 좌표 추출

### 거리 및 방향 계산
- **거리**: 픽셀 거리 × 실제 축척(m/pixel)
- **방위각**: `atan2(dy, dx)` 기반, 북쪽 0도 기준 시계방향
- **회전 각도**: 현재 바라보는 방향과 목표 방향의 차이 (-180° ~ +180°)

## 사용 방법

### 1. 기준 파일 준비

| 파일 | 설명 |
|------|------|
| `map.jpg` | 기준 지도 이미지 |
| `one.jpg` ~ `four.jpg` | 각 위치에서 촬영한 사진 |
| `as.xlsx` | 각 위치의 초기 방향 각도 데이터 |
| `video.mp4` | 목적지 안내 영상 |

### 2. 실행

```bash
python main.py
```

### 3. 조작 방법

| 키/동작 | 기능 |
|---------|------|
| `ESC` | 특징점 매칭 결과 확인 후 지도 화면으로 전환 |
| 지도 위 클릭 | 목적지 지정 → 거리 및 회전 각도 표시 |
| `q` | 안내 영상 재생 중 종료 |

## 지도 좌표 시스템

```
지도 이미지 해상도: 1282 × 706 px
실제 크기:         625.64m × 352.79m
축척:              약 0.488 m/pixel
```

방위각 기준:
- **0° = 북쪽 (위)**
- **90° = 동쪽 (오른쪽)**
- **180° = 남쪽 (아래)**
- **270° = 서쪽 (왼쪽)**
